# Instrucción inicial: pegar en Claude Code

> Lee `CLAUDE.md` y los documentos de `docs/`. Este es un proyecto nuevo: **APACH / Apapacho**. Antes de programar, inspecciona el directorio para no sobrescribir archivos ajenos, revisa coherencia de requisitos y crea/actualiza `docs/DECISIONES.md` con supuestos técnicos. Después **implementa Fase 1** según `docs/11-ROADMAP.md`: estructura real del repositorio, Docker Compose, PostgreSQL, FastAPI, React/Vite, migraciones, healthchecks, README y pruebas de humo. No te quedes solo en el plan. Ejecuta las comprobaciones posibles y deja constancia de resultados reales; si Docker no existe, documenta el bloqueo y da comandos reproducibles. Cuando termines esta fase, detente y resume archivos creados, comandos ejecutados, pruebas y siguiente fase. Nunca simules pruebas, usuarios o análisis APA como si fueran reales.

## Cómo continuar después
En una sesión posterior: «Lee `CLAUDE.md`, `docs/11-ROADMAP.md` y el módulo siguiente. Continúa con la primera fase pendiente y comprueba los criterios de aceptación».
